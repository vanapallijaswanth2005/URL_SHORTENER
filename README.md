## ✨ Features

- 🔗 **Instant URL Shortening**: Convert long, cumbersome URLs into clean, easily shareable short links.
- 🔐 **Secure Authentication**: Robust user authentication and authorization using **JWT (JSON Web Tokens)** and Spring Security.
- 🛡️ **Rate Limiting**: Built-in API rate limiting using **Bucket4j** to prevent abuse and ensure service stability.
- ⚡ **Blazing Fast Frontend**: A modern, responsive user interface built with **React 19** and powered by **Vite** for lightning-fast load times.
- 🗄️ **Persistent Storage**: Reliable data management utilizing **MySQL** and Spring Data JPA.

### Backend

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

Ensure you have the following installed:
- [Java Development Kit (JDK) 17+](https://adoptium.net/)
- [Node.js & npm](https://nodejs.org/) (for the frontend)
- [MySQL Server](https://dev.mysql.com/downloads/mysql/)

### 1. Database Setup

1. Open your MySQL client and create a new database:
   ```sql
   CREATE DATABASE urlshortener;
   ```
2. The tables will be automatically generated by Hibernate on startup.

### 2. Backend Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/vanapallijaswanth2005/URL_SHORTENER.git
   cd URL_SHORTENER
   ```

2. Configure your MySQL credentials. Open `src/main/resources/application.properties` and ensure your database settings are correct:
   ```properties
   spring.datasource.url=jdbc:mysql://localhost:3306/urlshortener?createDatabaseIfNotExist=true&useSSL=false&serverTimezone=UTC&allowPublicKeyRetrieval=true
   spring.datasource.username=root
   spring.datasource.password=YOUR_MYSQL_PASSWORD
   ```

3. Run the Spring Boot application using Maven:
   ```bash
   ./mvnw spring-boot:run
   ```
   *The backend will typically start on `http://localhost:8081`.*

### 3. Frontend Setup

1. Open a new terminal and navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install the dependencies:
   ```bash
   npm install
   ```

3. Start the Vite development server:
   ```bash
   npm run dev
   ```
   *The frontend will be accessible at the local URL provided by Vite (usually `http://localhost:5173`).*
